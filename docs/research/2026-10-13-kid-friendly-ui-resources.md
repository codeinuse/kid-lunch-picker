# Research: What free/open-licensed fonts, illustrations, mascots, animations, sounds, and UI kits can we use to make the kid-lunch-picker app more fun and kid-friendly, compatible with our stack?
**Date:** 2026-10-13  **Asked for:** restyle decision for the lunch tray app (assets must be permissively licensed, Next.js 16 + React 19 + Tailwind v4 compatible, appealing to ages 5–8)  **Versions checked:** next@16.4.0, react@19.3.0, tailwindcss@4, lottie-react@3.1.2, framer-motion@14.1.0, use-sound@5.0.0, @radix-ui/react-dialog@1.3.0 (from repo package.json)
## Answer
Use OFL rounded fonts via `next/font/google` (Fredoka for display, Baloo 2 or Nunito for body), CC0 illustrations vendored as SVG React components (Open Peeps; Humaaans only with an attribution-safety check — see caveats), unDraw only under its custom no-attribution license terms, free LottieFiles animations under the Lottie Simple License rendered with the already-installed `lottie-react` v3 (MIT, React 19 supported), CC0 Kenney audio packs plus Pixabay sounds under the Pixabay Content License played through the already-installed `use-sound`/Howler stack (both MIT), no kid-specific UI kit (keep Tailwind v4 + Radix primitives + framer-motion and apply child-UX guidance directly: 14pt type, 44–48px touch targets, WCAG AA contrast 4.5:1/3:1 large), while avoiding Storyset (attribution-required on the free tier) and Freesound (per-sample license variance, unverified).
## Findings
1. Fredoka is a rounded variable font (width + weight axes) under the SIL Open Font License 1.1, usable as a kid-friendly display face: [source](https://fonts.google.com/specimen/Fredoka) and [source](https://github.com/google/fonts/blob/main/ofl/fredoka/OFL.txt)
2. Baloo 2 by Ek Type is a rounded display family in variable weights (Regular to ExtraBold) and is libre-licensed, suited to playful headings: [source](https://fonts.google.com/specimen/Baloo+2) and [source](https://github.com/EkType/Baloo2)
3. Nunito (Vernon Adams, extended by Jacques Le Bailly) is a rounded-terminal sans superfamily with a matching non-rounded Nunito Sans, good for body text pairing with a display face: [source](https://fonts.google.com/specimen/Nunito)
4. Comfortaa by Johan Aakerlund is a rounded geometric sans explicitly OFL-1.1-licensed for personal and commercial use: [source](https://github.com/googlefonts/comfortaa)
5. Most Google Fonts (including the `ofl/` directory families above) use SIL OFL v1.1, which permits use, study, modification and redistribution as long as the font is not sold by itself, with a Reserved Font Name condition on some families: [source](https://github.com/google/fonts)
6. `next/font/google` automatically self-hosts any Google Font (no browser requests to Google), scopes fonts per-component, recommends variable fonts, and requires an explicit `weight` only for non-variable fonts: [source](https://nextjs.org/docs/app/getting-started/fonts.md) and [source](https://nextjs.org/docs/app/api-reference/components/font.md)
7. Open Peeps by Pablo Stanley is free for commercial and personal use under CC0 (no credit needed) and ships as composable SVG/PNG parts consumable by vendoring SVGs as React components: [source](https://www.openpeeps.com/)
8. Humaaans by Pablo Stanley is stated CC0 "free for commercial or personal use" on its official homepage, but a GitHub mirror of the same art is labeled CC BY 4.0, so treat it as attribution-uncertain (see caveats): [source](https://humaaans.com/) and [source](https://github.com/Calinou/humaaans)
9. Community React wrappers for Humaaans art (`humaaans`, `react-humaaans` npm packages) exist but are third-party, not vendor-supported, so prefer vendoring official SVGs: [source](https://github.com/jktzes/humaaans) and [source](https://github.com/jzarca01/react-humaaans)
10. unDraw illustrations are free for commercial and personal use with no attribution, but under a custom license that forbids replicating unDraw, redistributing in packs, building integrations, and any AI/ML training use: [source](https://undraw.co/license)
11. Storyset free illustrations REQUIRE attribution every use; attribution-free use requires a paid Flaticon premium subscription, so Storyset fails the zero-attribution preference: [source](https://storyset.com/faqs) and [source](https://storyset.com/terms)
12. Free LottieFiles animations are granted under the Lottie Simple License: free download, commercial use, modification, distribution and public display with NO attribution required (encouraged, and if given must be visible to end users), excluding compiling/scraping into a competing service: [source](https://lottiefiles.com/page/license) and [source](https://help.lottiefiles.com/animation-licensing-basics-)
13. `lottie-react` v3 (installed 3.1.2) is MIT-licensed, peers on react/react-dom >= 18.2 with React 18 and 19 both tested/supported, and uses named imports with a `src` prop taking a path, URL, or parsed animation object (`import { Lottie } from "lottie-react"; <Lottie src="/hero.json" autoplay loop />`): [source](https://www.npmjs.com/package/lottie-react) and [source](https://lottiereact.com/docs/get-started/installation) and [source](https://lottiereact.com/docs/migration)
14. Kenney game-audio packs (e.g. Interface Sounds 100 files, Voiceover Pack 90 files) are CC0 public domain, free even commercially, attribution NOT required (optional "Kenney" credit, logo reserved): [source](https://www.kenney.nl/support) and [source](https://kenney.nl/assets/interface-sounds) and [source](https://www.kenney.nl/assets/voiceover-pack)
15. The installed `use-sound` v5 hook is MIT-licensed and delegates all audio work to Howler.js, which is also MIT: [source](https://github.com/joshwcomeau/use-sound) and [source](https://github.com/goldfire/howler.js)
16. Pixabay sounds/music are released under the Pixabay Content License: free commercial and non-commercial use with NO attribution required, but Content may not be sold or distributed standalone — a custom license, not CC0, so keep download records: [source](https://pixabay.com/service/faq/) and [source](https://pixabay.com/service/license-summary)
17. No kid-specific React/Tailwind UI kit was found from a primary vendor source; the compatible base remains Tailwind CSS v4 utilities plus unstyled accessible Radix primitives plus framer-motion/Motion for animation, with kid-friendliness applied via theming (large radii, chunky borders, rounded fonts) rather than a new kit: [source](https://tailwindcss.com/docs) and [source](https://www.radix-ui.com/primitives/docs/overview/introduction) and [source](https://motion.dev/docs/react)
18. Nielsen Norman Group (Sherwin/Nielsen, 2019, n=125 children) requires distinguishing young (3–5), mid-range (6–8), and older (9–12) children, recommends 14pt type for young children vs 12pt for older, and advises avoiding scrolling and redundant navigation for young users: [source](https://www.nngroup.com/articles/childrens-websites-usability-issues/)
19. Apple HIG Accessibility sets default iOS/iPadOS control size 44x44pt (minimum 28x28pt) and WCAG AA contrast minimums of 4.5:1 (up to 17pt) and 3:1 (18pt+ or bold): [source](https://developer.apple.com/design/human-interface-guidelines/accessibility)
20. Material Design 3 requires touch targets of at least 48x48dp (visual may be smaller if the hit area meets 48dp) with ~8dp separation: [source](https://m3.material.io/foundations/designing/structure) and [source](https://m3.material.io/foundations/layout/grids-spacing/density)
21. WCAG 2.2 SC 1.4.3 Contrast (Minimum, AA) requires 4.5:1 for body text and 3:1 for large text (18pt / 14pt bold), with 7:1/4.5:1 at AAA: [source](https://www.w3.org/TR/WCAG22/) and [source](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
## Caveats & unverified
- Humaaans license conflict: official homepage says CC0 but the Calinou/humaaans mirror labels the same art CC BY 4.0 — verify by contacting the author or checking the current Gumroad/Figma distribution license before shipping without attribution; safest is Open Peeps (consistent CC0) or attribute Humaaans.
- LottieFiles platform Terms state Individual/Free plans are "strictly for non-commercial use" and commercial use needs Team/Enterprise, which appears aimed at platform-created/edited animations and sits uneasily beside the Simple License's commercial grant for downloaded public files — verify with support@lottiefiles.com which instrument covers our use, and always check the per-animation license badge: [source](https://lottiefiles.com/page/terms-and-conditions)
- LottieFiles free workspaces are capped at ~5 public-animation downloads (Sept 2026 help article), so shortlist animations before downloading: [source](https://help.lottiefiles.com/hc/en-us/articles/16240626895385-file-upload-and-download-limits-on-free-workspace)
- Unverified: Quicksand as an additional OFL rounded option (did not confirm its license file this pass — verify at fonts.google.com/specimen/Quicksand plus its google/fonts OFL entry).
- Unverified: Freesound.org per-sample licensing (mix of CC0/CC-BY/CC Sampling+) — avoided in recommendation; verify any candidate sample's license page before use.
- Unverified: exact `next/font` behavior on next@16.4.0 — docs checked are the current published Next.js docs (font module stable since the 13.2 rename); smoke-test `import { Fredoka, Baloo_2, Nunito } from 'next/font/google'` in the repo.
- Unverified: framer-motion@14 vs the Motion rebrand (motion.dev docs target the `motion` package); confirm installed v14 React 19 peer compatibility via its changelog before upgrading.
- WCAG 2.5.8 target-size numbers (24x24px AA / 44x44px AAA) were cross-checked via secondary aggregators only — verify against normative W3C text at https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html before citing in the restyle spec.
